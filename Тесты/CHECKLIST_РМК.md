# Чеклист тестирования РМК (Рабочее Место Кассира)

> **Конфигурация:** Public Trade Module
> **Объект:** `Обработка.РабочееМестоКассира`
> **Связанные документы:** `Документ.ЧекККМ`, `Документ.КассоваяСмена`
> **Дата создания:** 2026-02-23

---

## 1. УПРАВЛЕНИЕ КАССОВОЙ СМЕНОЙ

| # | Тест | Ожидаемый результат | Уровень |
|---|------|---------------------|---------|
| 1.1 | Открытие РМК без активной смены → отображается диалог "Открыть новую смену?" | Диалог появляется | Unit |
| 1.2 | Отказ от открытия смены → форма РМК закрывается | `Закрыть()` вызван | Unit |
| 1.3 | Подтверждение открытия смены → создаётся `КассоваяСмена` со `Статус = Открыта` | Документ создан, проведён | Unit |
| 1.4 | Открытие РМК при уже открытой смене → смена подключается без диалога | Форма открыта без вопроса | Unit |
| 1.5 | Закрытие смены → `КассоваяСмена.Статус = Закрыта`, `ДатаОкончания` заполнена | Документ обновлён | Unit |
| 1.6 | Закрытие смены с непроведёнными чеками → предупреждение пользователю | Диалог подтверждения | Smoke |
| 1.7 | Повторное открытие РМК после закрытия смены → предлагает открыть новую | Диалог появляется | Smoke |

## 11. АВТОМАТИЗИРУЕМЫЕ ЮНИТ-ТЕСТЫ (YAxUnit)

Следующие тесты можно покрыть через `ОМ_ТестыРМК.bsl`:

- **1.3, 1.4, 1.5** — создание/открытие/закрытие смены
- **2.1, 2.5, 2.7, 2.8, 2.9** — добавление товаров, пересчёт сумм
- **4.1, 4.2, 4.3, 4.6, 4.9, 4.10** — оформление чека, движения регистра
- **5.3, 5.4** — возврат, аннулирование
- **9.1, 9.2, 9.3** — граничные проверки

> Полный BSL-шаблон: `Тесты/YAxUnit/ОМ_ТестыРМК.bsl`
