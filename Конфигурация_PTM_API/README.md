# Конфигурация_PTM_API

Расширение **PTM_API** — универсальный внешний REST API (`/hs/ptm/v1`).

| Объект | Имя |
|--------|-----|
| HTTP-сервис | `Апи_Внешний` (RootURL=`ptm`) |
| Транспорт | `Апи_Транспорт` |
| Регистры | `Апи_Регистры` |
| Справочники | `Апи_Справочники` |
| API key | `Апи_Ключ` |
| Роль | `Апи_ОсновнаяРоль` |

## Первый запуск

1. Конфигуратор → Расширения → Создать: имя `PTM_API`, префикс `Апи_`, назначение AddOn, снять безопасный режим.
2. Либо сразу:

```bash
python scripts/deploy_ext.py --ext PTM_API --action Full
```

(если расширение ещё не создано в ИБ — создайте пустое в Конфигураторе, затем Full)

## Цикл

```bash
python scripts/deploy_ext.py --ext PTM_API --action Full
```

Спека: `Документация/API/`
