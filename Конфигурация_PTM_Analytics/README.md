# Конфигурация_PTM_Analytics

Папка для XML-файлов расширения **PTM_Analytics**.

## Подготовка (одноразово)

1. Открыть Конфигуратор → `Конфигурация → Расширения конфигурации → Создать`
   - Имя: `PTM_Analytics`
   - Синоним: `PTM Аналитика`
   - Режим безопасности: выключить
2. Сохранить расширение в ИБ
3. Выгрузить на диск:

```bash
python scripts/deploy_ext.py --ext PTM_Analytics --action Dump
```

После этого в папке появятся XML-файлы расширения.

## Рабочий цикл разработки

```bash
# Выгрузить из ИБ → редактировать → загрузить обратно
python scripts/deploy_ext.py --ext PTM_Analytics --action Dump     # ~ 5 сек
# ... редактирование XML/BSL файлов ...
python scripts/deploy_ext.py --ext PTM_Analytics --action Full     # ~ 15 сек
```
