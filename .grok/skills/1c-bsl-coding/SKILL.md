# Написание BSL (1С 8.3.27)

## Когда использовать

Любое создание или изменение файлов `*.bsl`.

## Перед правкой

1. Прочитай `.github/instructions/bsl.instructions.md` (авторитетный источник проекта).
2. Если объект незнаком — `context-mcp` → `resolve` / `get` по имени объекта.
3. Для форм — также skill `1c-form-generator` при работе с `Form.xml`.

## Кодировка файлов (критично)

Новые и перезаписанные `.bsl`:

- Кодировка: **UTF-8 с BOM**
- Переносы: **CRLF**
- Не используй plain `Write`/`create_file` без BOM — сломает загрузку в ИБ.

Паттерн Python-writer:

```python
path.write_bytes(b"\xef\xbb\xbf" + content.encode("utf-8"))
```

Или операции через `dev-mcp` / проверенные скрипты проекта.

## Абсолютные синтаксические правила

| ❌ Ошибка агента | ✅ Правильно |
|-----------------|-------------|
| `Новая Структура` | `Новый Структура` |
| `Новое Соответствие` | `Новый Соответствие` |
| `ТекущаяДата()` | `ТекущаяДатаСеанса()` |
| `Найти()` в строках | `СтрНайти()` |
| `ЭтаФорма` | `ЭтотОбъект` |
| `Сообщить()` | `СообщениеПользователю` |
| `РольДоступна()` | `ПравоДоступа()` |

## Структура модуля

- Директива (`&НаКлиенте`, `&НаСервере`, …) — **отдельная строка** перед сигнатурой
- Весь код в `#Область` … `#КонецОбласти`
- Имена: русский ВерблюжийРегистр, глагол+существительное

## Клиент и асинхронность

На клиенте: `Асинх`/`Ждать`. Запрещены `Вопрос()`, `Предупреждение()`, `ОткрытьФормуМодально()`, `ВвестиЧисло()` и аналоги без суффикса `Асинх`.

## Запросы

- Псевдоним у каждого поля SELECT
- `ЕСТЬNULL` при внешних соединениях
- Параметры: `Запрос.УстановитьПараметр()` — не конкатенация
- Не вызывать запросы в циклах
- `ОБЪЕДИНИТЬ ВСЕ`, не `ОБЪЕДИНИТЬ`

## После правки

**Обязательно** выполни skill `1c-verify` до завершения задачи.
