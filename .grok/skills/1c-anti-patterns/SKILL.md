# Антипаттерны BSL (1С)

## Когда использовать

- Ревью кода, рефакторинг, исправление «странного» поведения
- Перед деплоем (вместе с `1c-bsl-review`)
- Когда агент «пишет как в Python/Java/C#»

## Critical — блокируют деплой

| Антипаттерн | Почему плохо | Исправление |
|-------------|--------------|-------------|
| Запрос в цикле | O(n) round-trips к СУБД | Один запрос + выгрузка в ТЗ/соответствие |
| `Для Каждого` + обращение через точку к ссылке в цикле | O(n²) | Заранее выгрузить нужные поля запросом |
| `Выполнить(СтрокаКода)` / `Вычислить()` с вводом | Инъекция | Явная логика, без динамического кода |
| Модальные вызовы на клиенте | Блокировка UI, несовместимость веб/тонкий | `*Асинх()` + `Ждать` |
| `УстановитьПривилегированныйРежим(Истина)` без узкой области | Обход RLS | Минимальный блок + комментарий зачем |
| Код вне `#Область` | Стандарты 1С, проблемы ревью | Обернуть в области |
| Конкатенация в текст запроса | SQL-инъекция, план кэша | `УстановитьПараметр` |

## High — исправить до merge

| Антипаттерн | Исправление |
|-------------|-------------|
| `Новая`/`Новое` вместо `Новый` | Заменить конструктор |
| Метод без директивы | Добавить `&НаСервере` / `&НаКлиенте` / … |
| `Сообщить()` без привязки к полю | `СообщениеПользователю` + `Поле` |
| `ТекущаяДата()` | `ТекущаяДатаСеанса()` |
| `ВЫБРАТЬ ПЕРВЫЕ N` без `УПОРЯДОЧИТЬ ПО` | Добавить сортировку или пересмотреть логику |
| Транзакция без `Попытка`/`Исключение` | Канонический паттерн из `bsl.instructions.md` |
| Локальная переменная `ПараметрыВыбора`, `ОтборСтрок`, `СписокВыбора` в модуле формы | Переименовать — зарезервированы платформой |

## Medium — типичные ошибки агентов

- `ОписаниеОшибки()` как statement (нужно присвоение или передача в функцию)
- Em-dash `—` и non-breaking space U+00A0 в BSL-комментариях (ломают парсер)
- `ЖурналРегистрации.Записать` вместо `ЗаписьЖурналаРегистрации`
- `ПолучитьФорму()` вместо `ОткрытьФорму()` / `ОткрытьФормуАсинх()`
- Серверная логика в `&НаКлиенте` (обращение к БД с клиента)
- Клиентские вызовы в `&НаСервереБезКонтекста`

## Модули форм

- Обработчики событий: `&НаКлиенте` для UI, данные — через вызов сервера
- `ЭтотОбъект`, не `ЭтаФорма`
- Async: не забывать `Ждать` — иначе исключения теряются тихо

## Проведение документов

- Первая строка: `Если ОбменДанными.Загрузка Тогда Возврат; КонецЕсли;`
- `Движения.<Регистр>.Записывать = Истина` до заполнения

## Чек перед «готово»

1. Пройти таблицы Critical/High по изменённым файлам
2. Запустить `1c-verify`
