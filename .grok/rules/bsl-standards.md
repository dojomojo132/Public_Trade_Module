# BSL — обязательные стандарты (AdminReport, 8.3.27)

Применяется ко всем файлам `*.bsl` в `Конфигурация/`.

## Синтаксис

- Конструктор: только `Новый` (не `Новая`/`Новое`)
- Каждый метод: директива на отдельной строке перед сигнатурой
- Весь код в `#Область` … `#КонецОбласти`
- Кодировка: UTF-8 BOM + CRLF

## Клиент

- `Асинх`/`Ждать`; без модальных `Вопрос()`, `Предупреждение()`, `ОткрытьФормуМодально()`

## Запросы

- Псевдонимы полей; параметры через `УстановитьПараметр`; не в циклах

## После правки

Обязательно: skill `1c-verify` → `onec-mcp` `get_errors`.
