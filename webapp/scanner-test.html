Сравнение 3 движков: html5-qrcode, Quagga2, BarcodeDetector API

html5-qrcode v2.3.8 — обёртка над ZXing-js. Поддержка QR + 1D. FPS по умолчанию = 2 (медленно). Здесь: fps=10, только нужные форматы.
Quagga2 v1.12.1 — нативная локализация штрихкодов, активно поддерживается. Только 1D форматы. Для QR нужен отдельный плагин. Быстрое обнаружение.
BarcodeDetector API — нативный Web API (Chrome 83+). Без библиотеки, 0 KB. Самый быстрый на поддерживаемых устройствах. ⚠️ НЕ работает: iOS Safari, Firefox.
