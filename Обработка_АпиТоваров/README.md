# Обработка «АпиТоваров»

Загрузка товаров и групп из API → отображение в таблице с фильтром по группам.

## Настройка в конфигураторе

### 1. Создать обработку

Имя: `АпиТоваров` (внешняя или встроенная — без разницы).

### 2. Табличные части

#### «Товары» — **пустая** (0 колонок в метаданных)

Все 19 колонок создаются кодом через `ИзменитьРеквизиты` + `Элементы.Добавить` при открытии формы.
Состав и типы определяются в `СоздатьДинамическиеКолонкиТоваров()` + `ПолучитьТипКолонки()`.

#### «НастройкаПолей» — управление видимостью колонок

| Имя колонки | Тип    | Длина |
|-------------|--------|------:|
| Имя         | Строка | 50    |
| Заголовок   | Строка | 100   |
| Включено    | Булево | —     |

Предзаполняется при открытии формы (все поля товаров).
Галка `Включено` управляет видимостью соответствующей колонки в таблице «Товары».

> Имена элементов колонок таблицы Товары: `Товары` + имя поля (напр. `Товарыname`, `Товарыprice`).

### 3. Реквизиты формы (не объекта!)

| Имя               | Тип    | Назначение                              |
|--------------------|--------|-----------------------------------------|
| ФильтрГруппа       | Число  | ID выбранной группы (0 = все)           |
| АдресВсехТоваров   | Строка | Адрес во временном хранилище (скрытый)  |

### 4. Элементы формы

```
┌─────────────────────────────────────────────────────┐
│  [ФильтрГруппа ▼ <Все группы>]   [Загрузить]       │
├──────────────────────┬──────────────────────────────┤
│  НастройкаПолей      │  Товары                      │
│  ☑ name              │  id │ name │ price │ tax │...│
│  ☑ price             │  ...│ ...  │ ...   │ ... │...│
│  ☐ barcode           │                              │
│  ...                 │                              │
└──────────────────────┴──────────────────────────────┘
```

- **ФильтрГруппа** — ПолеВвода, вид: `ПолеВыбораИзСписка`
  - Обработчик: `ПриИзменении` → `ФильтрГруппаПриИзменении`
- **НастройкаПолей** — ТаблицаФормы, путь к данным: `Объект.НастройкаПолей`
  - Колонки: Заголовок (только чтение), Включено (флажок)
  - Обработчик: `Включено.ПриИзменении` → `НастройкаПолейВключеноПриИзменении`
- **Товары** — создаётся кодом (`СоздатьДинамическиеКолонкиТоваров`), НЕ размещать на форме вручную
- **Загрузить** — КнопкаКоманды формы, действие → `Загрузить`

### 5. Модуль формы

Вставить содержимое файла `ФормаМодуль.bsl`.

## Подключение к API

В функции `ПолучитьJSONОтAPI` раскомментировать HTTP-блок и указать адрес сервера:

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443,
    , , , , Новый ЗащищенноеСоединениеOpenSSL);
```

После подключения удалить функции `ТестовыеДанныеТоваров()` и `ТестовыеДанныеГрупп()`.

## Примечания

- `price` приходит в копейках → делится на 100 (198.00 грн)
- `tax` приходит в сотых долях → делится на 100 (20.00%)
- `uktZed` и `barcode` могут быть `null` → обрабатываются как пустая строка
- Фильтр не перезагружает данные — только меняет отображение из хранилища
