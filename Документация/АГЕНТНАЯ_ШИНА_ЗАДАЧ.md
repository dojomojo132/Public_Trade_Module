# Агентная шина задач (Agent Task Bus)

> Система параллельной разработки: 1 оркестратор + N агентов VS Code Copilot на разных машинах.
> Все файлы: `scripts/agent_bus/`

---

## Архитектура

```
Оркестратор (ПК #1)
    ↓  публикует задачи
SQLite БД (.agent-bus/bus.db)  ←→  bus_monitor.py (наблюдение)
    ↑  агенты сами берут задачи (atomic poll)
Copilot A (ПК #2)   Copilot B (ПК #3)   Copilot C (ПК #4)
```

**Транспорт:**
- LAN — SQLite на сетевой папке (SMB/NFS)
- Internet — FastAPI REST сервер (`api_server.py`) + Tailscale/ngrok

---

## Файлы системы

| Файл | Назначение |
|------|-----------|
| `protocol.py` | Датаклассы: Task, AgentState, TaskCommand, OrchestratorCommand |
| `bus.py` | SQLite шина — publish, claim, complete, fail, retry, heartbeat |
| `orchestrator_loop.py` | Главный цикл: мониторинг, offline-детект, stuck-задачи |
| `agent_worker.py` | Автономный Python-воркер (без Copilot) |
| `api_server.py` | FastAPI REST-шина для cross-internet |
| `bus_reader.py` | Copilot: взять задачу из шины → промпт |
| `bus_report.py` | Copilot: сдать результат + git commit |
| `bus_monitor.py` | Live ANSI-дашборд: агенты, задачи, алерты |
| `bus_daemon.py` | Запуск любого компонента в фоновом режиме |
| `demo_local.py` | Локальная демонстрация (5 задач с зависимостями) |
| `README.md` | Краткая справка по компонентам |

---

## Жизненный цикл задачи

```
pending → active → done
            ↓ (ошибка)
         failed → pending  (retry_count < max_retries=2)
              ↓ (все попытки)
           failed (финальный)

blocked → pending  (автоматически при завершении depends_on)
```

## Быстрый старт

### Локально (1 ПК, несколько агентов в потоках)
```bash
python scripts/agent_bus/demo_local.py
```

### LAN (общая папка)

**ПК #1 (оркестратор):**
```bash
# В фоне
python scripts/agent_bus/bus_daemon.py start orchestrator --bus-dir //server/share/agent-bus

# Мониторинг
python scripts/agent_bus/bus_daemon.py start monitor --bus-dir //server/share/agent-bus

# Статус фоновых процессов
python scripts/agent_bus/bus_daemon.py status

# Логи оркестратора
python scripts/agent_bus/bus_daemon.py logs orchestrator --lines 50
```

**ПК #2 (Copilot-агент):**
```bash
# 1. Взять задачу из шины
python scripts/agent_bus/bus_reader.py --agent-id copilot-backend --bus-dir //server/share/agent-bus

# 2. Copilot читает .github/prompts/current_task.prompt.md и выполняет

# 3. Сдать результат
python scripts/agent_bus/bus_report.py --success --summary "реализован модуль X"
# или при ошибке:
python scripts/agent_bus/bus_report.py --failed "ошибка компиляции BSL"
```

### Internet (REST API)

**Сервер:**
```bash
python scripts/agent_bus/bus_daemon.py start api --port 8765
# Опционально: установить переменную AGENT_BUS_API_KEY=secret
```

**Удалённый агент** — использует `BusHttpClient` из `api_server.py`:
```python
from scripts.agent_bus.api_server import BusHttpClient
client = BusHttpClient("http://your-server:8765", api_key="secret")
task = client.claim_next_task("copilot-remote", "frontend")
client.complete_task(task["task_id"], "copilot-remote", "done", "реализовано")
```

## Надёжность

| Проблема | Детектирование | Реакция |
|---------|---------------|---------|
| Агент упал | Heartbeat не обновлялся >300 сек | Задача → pending, запись в alerts.jsonl |
| Задача зависла | Висит дольше `estimated_minutes × 2.0` | CANCEL агенту + задача → pending |
| Повторные сбои ×5 | Счётчик `_offline_warn_count` | Уровень ERROR в alert-логе |
| Задача упала | `fail_task()` | Авторетрай до 2 раз → потом failed |
| MCP недоступен | Exception → graceful fallback | Работа по файлам, предупреждение |

**Alert-лог:** `.agent-bus/.agent-bus-alerts.jsonl` — JSONL, одна запись на событие.

## Публикация плана задач

```python
from scripts.agent_bus.orchestrator_loop import Orchestrator
from scripts.agent_bus.protocol import Task, TaskCommand

orc = Orchestrator(bus_dir=".agent-bus")

# Создать задачи (depends_on — по task_id)
tasks = [
    Task(direction="backend",  priority=1,
         command=TaskCommand(title="Создать API", description="...")),
    Task(direction="frontend", priority=1,
         command=TaskCommand(title="Сверстать форму", description="...",
                             depends_on=["<backend-task-id>"])),
]
ids = orc.publish_plan(tasks)
orc.run()  # или в фоне через bus_daemon.py
```

## Структура БД (SQLite)

```sql
tasks (
    task_id, direction, priority, status,   -- описание задачи
    assigned_to, created_at, started_at,    -- назначение
    retry_count INTEGER DEFAULT 0,          -- сколько раз уже пробовал
    max_retries INTEGER DEFAULT 2,          -- максимум попыток
    command_json, result_json               -- задача и результат
)
agent_states (agent_id, status, heartbeat, direction, current_task_id, ...)
inbox        (agent_id, command_json, ...)   -- команды от оркестратора
results      (task_id, agent_id, outcome, summary, ...)
```

## Управление фоновыми процессами (bus_daemon.py)

```bash
# Запустить
python scripts/agent_bus/bus_daemon.py start orchestrator
python scripts/agent_bus/bus_daemon.py start monitor
python scripts/agent_bus/bus_daemon.py start api --port 8765
python scripts/agent_bus/bus_daemon.py start agent --agent-id copilot-1 --direction backend

# Статус всех
python scripts/agent_bus/bus_daemon.py status

# Логи
python scripts/agent_bus/bus_daemon.py logs orchestrator --lines 100

# Остановить
python scripts/agent_bus/bus_daemon.py stop orchestrator
```

PID-файлы и логи: `.agent-bus-daemon/<name>.pid.json`, `.agent-bus-daemon/<name>.log`
