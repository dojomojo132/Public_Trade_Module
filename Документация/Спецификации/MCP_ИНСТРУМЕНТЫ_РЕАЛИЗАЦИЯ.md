## 1. ТЕКУЩЕЕ СОСТОЯНИЕ

### 1.1 Установленные компоненты

| Компонент | Статус | Описание |
|-----------|--------|----------|
| `mcp_APIBackend` (HTTPСервис) | ✅ Установлен | HTTP-эндпоинт: `http://localhost/PTM/hs/mcp/mcp` |
| `mcp_ИнструментДанныеОКонфигурации` | ✅ Работает | `list_metadata_objects`, `get_metadata_structure` |
| `mcp_РесурсОписаниеСинтаксисаВстроенногоЯзыка` | ✅ Работает | Ресурс с описанием синтаксиса BSL |
| `mcp_УправлениеСервером` | ✅ Работает | Внутреннее управление MCP-сервером |
| `mcp_ОбщегоНазначения` | ✅ Работает | JSON-утилиты |
| `mcp_Метаданные` | ✅ Работает | Схемы параметров, таблицы инструментов |
| `mcp_Выполнение` | ✅ Работает | Вызов методов контейнеров |
| `mcp_КонтейнерыПовтИсп` | ✅ Работает | Кеширование таблиц |
| `mcp_Содержимое` | ✅ Работает | Формирование содержимого ответов |
| `mcp_ОсновнаяРоль` (Роль) | ✅ Установлен | Роль доступа к MCP |
| VS Code MCP-клиент | ✅ Настроен | `%APPDATA%\Code\User\mcp.json` → `mcp_1c_torgovly` |

### 1.2 Используемые инструменты (сейчас)

| Инструмент | Вызов из VS Code | Назначение |
|-----------|------------------|------------|
| `list_metadata_objects` | `mcp_mcp_1c_torgov_list_metadata_objects` | Список объектов метаданных по типу с фильтром |
| `get_metadata_structure` | `mcp_mcp_1c_torgov_get_metadata_structure` | Структура объекта (реквизиты, ТЧ, измерения, ресурсы) |

### 1.3 Архитектура расширения

```
VS Code Copilot Agent
    │
    ├─ mcp_mcp_1c_torgov_list_metadata_objects(metaType, nameMask, maxItems)
    ├─ mcp_mcp_1c_torgov_get_metadata_structure(metaType, name)
    │
    ▼
HTTP POST → http://localhost/PTM/hs/mcp/mcp
    │
    ▼
mcp_APIBackend (HTTP-сервис в расширении)
    │  JSON-RPC: {"method": "tools/call", "params": {"name": "...", "arguments": {...}}}
    │
    ├─ mcp_КонтейнерыПовтИсп → кешированные таблицы инструментов/ресурсов/промптов
    ├─ mcp_Метаданные → автообнаружение контейнеров через подсистемы
    ├─ mcp_Выполнение → вызов ВыполнитьИнструмент() у нужной обработки
    │
    ▼
Обработки-контейнеры (подсистема mcp_КонтейнерыИнструментов):
    ├── mcp_ИнструментДанныеОКонфигурации  ← list_metadata_objects, get_metadata_structure
    └── [НОВЫЕ ОБРАБОТКИ]                   ← наши дополнительные инструменты
```

### 1.4 Принцип добавления нового инструмента

1. Создать обработку с префиксом `mcp_Инструмент...`
2. Включить в подсистему `mcp_КонтейнерыИнструментов`
3. Реализовать в модуле менеджера:
   - `Процедура ДобавитьИнструменты(Инструменты) Экспорт` — описание и JSON-схема параметров
   - `Функция ВыполнитьИнструмент(ИмяИнструмента, Аргументы) Экспорт` — логика выполнения
4. **Никаких изменений в HTTP-сервисе или других модулях не требуется**
5. После добавления в расширение: загрузить `.cfe` → обновить конфигурацию ИБ

### 2.1 Приоритет 1 — Критически полезно

#### 2.1.1 `execute_query` — Выполнение запроса 1С

**Зачем:** Проверка данных в регистрах, остатков, движений документов прямо из агента. Сейчас агент слеп — пишет код проведения, но не может проверить результат.

**Параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `queryText` | string | Да | Текст запроса на языке 1С |
| `params` | object | Нет | Параметры запроса (ключ=имя, значение=значение) |
| `maxRows` | number | Нет | Максимум строк результата (по умолчанию 100) |

**Примеры вызовов:**
```
// Проверить остатки товаров
execute_query(
  queryText: "ВЫБРАТЬ Номенклатура.Наименование, КоличествоОстаток 
               ИЗ РегистрНакопления.ОстаткиТоваров.Остатки()",
  maxRows: 50
)

// Проверить движения конкретного документа
execute_query(
  queryText: "ВЫБРАТЬ * ИЗ РегистрНакопления.ОстаткиТоваров 
               ГДЕ Регистратор = &Док",
  params: {"Док": "Документ.ЧекККМ.FindByNumber:00001"}
)

// Цены номенклатуры
execute_query(
  queryText: "ВЫБРАТЬ Номенклатура.Наименование, Цена, ТипЦены.Наименование 
               ИЗ РегистрСведений.ЦеныНоменклатуры.СрезПоследних()"
)
```

**Реализация BSL (модуль менеджера):**

```bsl
Процедура ДобавитьИнструменты(Инструменты) Экспорт
    
    МассивПараметров = Новый Массив;
    
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "queryText", "string", "Текст запроса на языке 1С", , Истина));
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "maxRows", "number", "Максимальное количество строк результата", 100));
    
    СхемаПараметров = mcp_Метаданные.СхемаПараметровИнструмента(МассивПараметров);
    
    mcp_Метаданные.ДобавитьИнструмент(
        Инструменты,
        "execute_query",
        "Выполнение произвольного запроса 1С. Возвращает результат в текстовом виде (таблица). Используйте для проверки данных в регистрах, остатков, движений документов.",
        СхемаПараметров);
    
КонецПроцедуры

Функция ВыполнитьИнструмент(ИмяИнструмента, Аргументы) Экспорт
    
    Если ИмяИнструмента = "execute_query" Тогда
        Возврат ВыполнитьЗапрос(Аргументы);
    КонецЕсли;
    
    ВызватьИсключение "Неизвестный инструмент: " + ИмяИнструмента;
    
КонецФункции

Функция ВыполнитьЗапрос(Аргументы)
    
    ТекстЗапроса = Аргументы.queryText;
    Лимит = ?(Аргументы.Свойство("maxRows"), Аргументы.maxRows, 100);
    
    Запрос = Новый Запрос(ТекстЗапроса);
    
    // Установка параметров, если переданы
    Если Аргументы.Свойство("params") Тогда
        Для Каждого КлючЗначение Из Аргументы.params Цикл
            Запрос.УстановитьПараметр(КлючЗначение.Ключ, КлючЗначение.Значение);
        КонецЦикла;
    КонецЕсли;
    
    Результат = Запрос.Выполнить();
    
    Если Результат.Пустой() Тогда
        Возврат "Запрос вернул пустой результат (0 строк)";
    КонецЕсли;
    
    Выборка = Результат.Выбрать();
    Колонки = Результат.Колонки;
    
    // Формируем заголовок
    МассивКолонок = Новый Массив;
    Для Каждого Колонка Из Колонки Цикл
        МассивКолонок.Добавить(Колонка.Имя);
    КонецЦикла;
    
    СтрокиРезультата = Новый Массив;
    СтрокиРезультата.Добавить(СтрСоединить(МассивКолонок, " | "));
    СтрокиРезультата.Добавить(СтрСоединить(Новый Массив(МассивКолонок.Количество(), "---"), " | "));
    
    Счетчик = 0;
    Пока Выборка.Следующий() И Счетчик < Лимит Цикл
        МассивЗначений = Новый Массив;
        Для Каждого Колонка Из Колонки Цикл
            Значение = Выборка[Колонка.Имя];
            МассивЗначений.Добавить(?(Значение = Неопределено, "NULL", Строка(Значение)));
        КонецЦикла;
        СтрокиРезультата.Добавить(СтрСоединить(МассивЗначений, " | "));
        Счетчик = Счетчик + 1;
    КонецЦикла;
    
    Если Выборка.Количество() > Лимит Тогда
        СтрокиРезультата.Добавить("... ещё " + Строка(Выборка.Количество() - Лимит) + " строк (ограничение maxRows=" + Строка(Лимит) + ")");
    КонецЕсли;
    
    Возврат СтрСоединить(СтрокиРезультата, Символы.ПС);
    
КонецФункции
```

#### 2.1.2 `get_object_module` — Получение BSL-кода модуля из ИБ

**Зачем:** Сверка кода в ИБ с кодом на диске. Чтение модулей расширений (БПО), которых нет на диске. Анализ кода, который реально выполняется.

**Параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `metaType` | string | Да | Тип объекта (Catalogs, Documents, DataProcessors, CommonModules) |
| `name` | string | Да | Имя объекта |
| `moduleType` | string | Нет | Тип модуля: ObjectModule, ManagerModule, FormModule (по умолчанию ObjectModule) |
| `formName` | string | Нет | Имя формы (если moduleType=FormModule) |

**Реализация BSL:**

```bsl
Процедура ДобавитьИнструменты(Инструменты) Экспорт
    
    МассивПараметров = Новый Массив;
    
    СписокТипов = "Catalogs,Documents,DataProcessors,Reports,CommonModules,InformationRegisters,AccumulationRegisters";
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "metaType", "string", "Тип объекта метаданных", , Истина, СписокТипов));
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "name", "string", "Имя объекта метаданных", , Истина));
    
    СписокТиповМодулей = "ObjectModule,ManagerModule,FormModule,RecordSetModule,CommandModule";
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "moduleType", "string", "Тип модуля", "ObjectModule", , СписокТиповМодулей));
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "formName", "string", "Имя формы (если moduleType=FormModule)"));
    
    СхемаПараметров = mcp_Метаданные.СхемаПараметровИнструмента(МассивПараметров);
    
    mcp_Метаданные.ДобавитьИнструмент(
        Инструменты,
        "get_object_module",
        "Получить текст BSL-модуля объекта метаданных из информационной базы. Включая модули расширений.",
        СхемаПараметров);
    
КонецПроцедуры

Функция ВыполнитьИнструмент(ИмяИнструмента, Аргументы) Экспорт
    
    Если ИмяИнструмента = "get_object_module" Тогда
        Возврат ПолучитьТекстМодуля(Аргументы);
    КонецЕсли;
    
    ВызватьИсключение "Неизвестный инструмент: " + ИмяИнструмента;
    
КонецФункции

Функция ПолучитьТекстМодуля(Аргументы)
    
    МетаТип = Аргументы.metaType;
    Имя = Аргументы.name;
    ТипМодуля = ?(Аргументы.Свойство("moduleType"), Аргументы.moduleType, "ObjectModule");
    
    // Получаем объект метаданных
    Попытка
        КоллекцияМД = Метаданные[МетаТип];
    Исключение
        ВызватьИсключение "Неизвестный тип метаданных: " + МетаТип;
    КонецПопытки;
    
    МетаданныеОбъекта = КоллекцияМД.Найти(Имя);
    Если МетаданныеОбъекта = Неопределено Тогда
        ВызватьИсключение "Объект не найден: " + МетаТип + "." + Имя;
    КонецЕсли;
    
    // Для общих модулей — только один модуль
    Если МетаТип = "CommonModules" Тогда
        Возврат МетаданныеОбъекта.ПолучитьТекстМодуля();
    КонецЕсли;
    
    // Получаем нужный модуль
    Если ТипМодуля = "ObjectModule" Тогда
        Возврат МетаданныеОбъекта.ПолучитьТекстМодуляОбъекта();
    ИначеЕсли ТипМодуля = "ManagerModule" Тогда
        Возврат МетаданныеОбъекта.ПолучитьТекстМодуляМенеджера();
    ИначеЕсли ТипМодуля = "FormModule" Тогда
        ИмяФормы = ?(Аргументы.Свойство("formName"), Аргументы.formName, "");
        Если Не ЗначениеЗаполнено(ИмяФормы) Тогда
            ВызватьИсключение "Для FormModule необходимо указать параметр formName";
        КонецЕсли;
        Форма = МетаданныеОбъекта.Формы.Найти(ИмяФормы);
        Если Форма = Неопределено Тогда
            ВызватьИсключение "Форма не найдена: " + ИмяФормы;
        КонецЕсли;
        Возврат Форма.ПолучитьТекстМодуля();
    ИначеЕсли ТипМодуля = "RecordSetModule" Тогда
        Возврат МетаданныеОбъекта.ПолучитьТекстМодуляНабораЗаписей();
    КонецЕсли;
    
    ВызватьИсключение "Неизвестный тип модуля: " + ТипМодуля;
    
КонецФункции
```

#### 2.1.3 `execute_code` — Выполнение произвольного BSL-кода

**Зачем:** Тестирование логики, проверка формул, запуск исправлений данных, отладка без конфигуратора.

**⚠️ БЕЗОПАСНОСТЬ:** Выполнять в безопасном режиме по умолчанию. Добавить параметр `safeMode`.

**Параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `code` | string | Да | BSL-код для выполнения |
| `safeMode` | boolean | Нет | Безопасный режим (по умолчанию true) |

**Реализация BSL:**

```bsl
Процедура ДобавитьИнструменты(Инструменты) Экспорт
    
    МассивПараметров = Новый Массив;
    
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "code", "string", "BSL-код для выполнения на сервере 1С", , Истина));
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "safeMode", "boolean", "Безопасный режим (ограничивает доступ к ОС, файлам). По умолчанию true.", Истина));
    
    СхемаПараметров = mcp_Метаданные.СхемаПараметровИнструмента(МассивПараметров);
    
    mcp_Метаданные.ДобавитьИнструмент(
        Инструменты,
        "execute_code",
        "Выполнить произвольный BSL-код на сервере 1С. Код должен присвоить результат переменной Результат. Возвращает строковое представление Результат.",
        СхемаПараметров);
    
КонецПроцедуры

Функция ВыполнитьИнструмент(ИмяИнструмента, Аргументы) Экспорт
    
    Если ИмяИнструмента = "execute_code" Тогда
        Возврат ВыполнитьКод(Аргументы);
    КонецЕсли;
    
    ВызватьИсключение "Неизвестный инструмент: " + ИмяИнструмента;
    
КонецФункции

Функция ВыполнитьКод(Аргументы)
    
    Код = Аргументы.code;
    БезопасныйРежим = ?(Аргументы.Свойство("safeMode"), Аргументы.safeMode, Истина);
    
    Если БезопасныйРежим Тогда
        УстановитьБезопасныйРежим(Истина);
    КонецЕсли;
    
    Результат = Неопределено;
    
    Попытка
        Выполнить(Код);
    Исключение
        ВызватьИсключение "Ошибка выполнения кода: " + ОписаниеОшибки();
    КонецПопытки;
    
    Если Результат = Неопределено Тогда
        Возврат "Код выполнен успешно. Переменная Результат не была установлена.";
    КонецЕсли;
    
    Возврат Строка(Результат);
    
КонецФункции
```

#### 2.1.4 `get_register_data` — Чтение данных регистра

**Зачем:** Проверка остатков товаров, цен, кассовых смен — без написания запросов вручную.

|----------|-----|-------------|----------|

| `maxRows` | number | Нет | Максимум строк (по умолчанию 100) |

**Реализация BSL:**

```bsl
Процедура ДобавитьИнструменты(Инструменты) Экспорт
    
    МассивПараметров = Новый Массив;
    
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(

    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(

    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "period", "string", "Дата среза в формате ISO (ГГГГ-ММ-ДДТЧЧ:ММ:СС)"));
    МассивПараметров.Добавить(mcp_Метаданные.ПараметрИнструмента(
        "maxRows", "number", "Максимальное количество строк результата", 100));
    
    СхемаПараметров = mcp_Метаданные.СхемаПараметровИнструмента(МассивПараметров);
    
    mcp_Метаданные.ДобавитьИнструмент(
        Инструменты,
        "get_register_data",
        "Чтение данных регистра накопления или сведений. Поддерживает режимы: Balance (остатки), Turnovers (обороты), SliceLast (срез последних), All (все записи).",
        СхемаПараметров);
    
КонецПроцедуры
```

#### 2.1.5 `get_document_movements` — Движения документа по регистрам

**Зачем:** Мониторинг проведения: проверить, что документ (ЧекККМ, ПриходТовара) создал правильные движения.

**Параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `documentType` | string | Да | Тип документа (например, "ЧекККМ") |
| `documentNumber` | string | Да | Номер документа |
| `maxRows` | number | Нет | Максимум строк на регистр (по умолчанию 50) |

**Реализация BSL:**

```bsl
Функция ПолучитьДвиженияДокумента(Аргументы)
    
    ТипДокумента = Аргументы.documentType;
    НомерДокумента = Аргументы.documentNumber;
    Лимит = ?(Аргументы.Свойство("maxRows"), Аргументы.maxRows, 50);
    
    // Найти документ по номеру
    МДДокумента = Метаданные.Документы.Найти(ТипДокумента);
    Если МДДокумента = Неопределено Тогда
        ВызватьИсключение "Тип документа не найден: " + ТипДокумента;
    КонецЕсли;
    
    Менеджер = Документы[ТипДокумента];
    ДокСсылка = Менеджер.НайтиПоНомеру(НомерДокумента);
    
    Если ДокСсылка.Пустая() Тогда
        ВызватьИсключение "Документ не найден: " + ТипДокумента + " №" + НомерДокумента;
    КонецЕсли;
    
    РезультатМассив = Новый Массив;
    РезультатМассив.Добавить("Документ: " + Строка(ДокСсылка) + " от " + Строка(ДокСсылка.Дата));
    РезультатМассив.Добавить("Проведён: " + ?(ДокСсылка.Проведен, "Да", "Нет"));
    РезультатМассив.Добавить("");
    
    // Обойти все регистры, в которых документ может делать движения
    Для Каждого РегМД Из МДДокумента.Движения Цикл
        
        Запрос = Новый Запрос;
        Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ " + Строка(Лимит) + " * ИЗ " + РегМД.ПолноеИмя() + " ГДЕ Регистратор = &Док";
        Запрос.УстановитьПараметр("Док", ДокСсылка);
        
        Результат = Запрос.Выполнить();
        
        Если Не Результат.Пустой() Тогда
            РезультатМассив.Добавить("=== " + РегМД.ПолноеИмя() + " ===");
            
            Выборка = Результат.Выбрать();
            Колонки = Результат.Колонки;
            
            // Заголовок
            МассивКолонок = Новый Массив;
            Для Каждого Колонка Из Колонки Цикл
                Если Колонка.Имя <> "Регистратор" Тогда
                    МассивКолонок.Добавить(Колонка.Имя);
                КонецЕсли;
            КонецЦикла;
            РезультатМассив.Добавить(СтрСоединить(МассивКолонок, " | "));
            
            Пока Выборка.Следующий() Цикл
                МассивЗначений = Новый Массив;
                Для Каждого Колонка Из Колонки Цикл
                    Если Колонка.Имя <> "Регистратор" Тогда
                        Значение = Выборка[Колонка.Имя];
                        МассивЗначений.Добавить(?(Значение = Неопределено, "NULL", Строка(Значение)));
                    КонецЕсли;
                КонецЦикла;
                РезультатМассив.Добавить(СтрСоединить(МассивЗначений, " | "));
            КонецЦикла;
            
            РезультатМассив.Добавить("");
        КонецЕсли;
        
    КонецЦикла;
    
    Если РезультатМассив.Количество() = 3 Тогда
        РезультатМассив.Добавить("Движений не найдено.");
    КонецЕсли;
    
    Возврат СтрСоединить(РезультатМассив, Символы.ПС);
    
КонецФункции
```

#### 2.3.1 `get_event_log` — Журнал регистрации

**Зачем:** Прямой доступ к ошибкам из ЖР без `monitor-errors.ps1`.

**Параметры:**

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `level` | string | Нет | Уровень: Error, Warning, Information, Note. По умолчанию Error |
| `lastMinutes` | number | Нет | За последние N минут (по умолчанию 30) |
| `maxRows` | number | Нет | Максимум записей (по умолчанию 50) |
| `eventFilter` | string | Нет | Фильтр по событию (подстрока) |

**Реализация BSL:**

```bsl
Функция ПрочитатьЖурналРегистрации(Аргументы)
    
    Уровень = ?(Аргументы.Свойство("level"), Аргументы.level, "Error");
    ЗаМинут = ?(Аргументы.Свойство("lastMinutes"), Аргументы.lastMinutes, 30);
    Лимит = ?(Аргументы.Свойство("maxRows"), Аргументы.maxRows, 50);
    
    Отбор = Новый Структура;
    
    Если Уровень = "Error" Тогда
        Отбор.Вставить("Уровень", УровеньЖурналаРегистрации.Ошибка);
    ИначеЕсли Уровень = "Warning" Тогда
        Отбор.Вставить("Уровень", УровеньЖурналаРегистрации.Предупреждение);
    КонецЕсли;
    
    Отбор.Вставить("ДатаНачала", ТекущаяДатаСеанса() - ЗаМинут * 60);
    Отбор.Вставить("ДатаОкончания", ТекущаяДатаСеанса());
    
    СобытияЖР = Новый ТаблицаЗначений;
    ВыгрузитьЖурналРегистрации(СобытияЖР, Отбор, , , Лимит);
    
    Если СобытияЖР.Количество() = 0 Тогда
        Возврат "Записей в журнале регистрации не найдено (за последние " + Строка(ЗаМинут) + " мин, уровень: " + Уровень + ")";
    КонецЕсли;
    
    МассивСтрок = Новый Массив;
    МассивСтрок.Добавить("Журнал регистрации: " + Строка(СобытияЖР.Количество()) + " записей");
    МассивСтрок.Добавить("");
    
    Для Каждого Строка Из СобытияЖР Цикл
        МассивСтрок.Добавить("--- " + Строка(Строка.Дата) + " ---");
        МассивСтрок.Добавить("Событие: " + Строка(Строка.Событие));
        МассивСтрок.Добавить("Уровень: " + Строка(Строка.Уровень));
        МассивСтрок.Добавить("Комментарий: " + Строка(Строка.Комментарий));
        Если ЗначениеЗаполнено(Строка.Данные) Тогда
            МассивСтрок.Добавить("Данные: " + Строка(Строка.Данные));
        КонецЕсли;
        Если ЗначениеЗаполнено(Строка.Метаданные) Тогда
            МассивСтрок.Добавить("Метаданные: " + Строка(Строка.Метаданные));
        КонецЕсли;
        МассивСтрок.Добавить("");
    КонецЦикла;
    
    Возврат СтрСоединить(МассивСтрок, Символы.ПС);
    
КонецФункции
```

## 4. ПОРЯДОК РЕАЛИЗАЦИИ

### Фаза 1 — Минимально жизнеспособный набор (1-2 дня)

1. **`mcp_ИнструментЗапросыИДанные`** — `execute_query` + `get_register_data` + `get_document_movements`
   - Максимальный эффект: агент "прозревает" и видит данные в ИБ
   - 1 обработка, ~150 строк BSL

2. **`mcp_ИнструментСправочнаяИнформация`** — `list_enum_values`
   - Быстро реализуется (~30 строк), часто нужен

### Фаза 2 — Расширенная функциональность (2-3 дня)

3. **`mcp_ИнструментМодулиИКод`** — `get_object_module` + `execute_code`
4. **`mcp_ИнструментАдминистрирование`** — `get_users_list` + `get_event_log`

### Фаза 3 — Полный набор (по мере необходимости)

5. `get_predefined_values`, `get_form_structure`, `get_subsystem_content`
6. `find_references`, `post_document`
7. Ресурсы и промпты

## 5. ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ ОБРАБОТКИ В РАСШИРЕНИЕ

### 5.1 Создание обработки (в конфигураторе)

1. Открыть расширение MCP_Сервер в конфигураторе
2. Добавить → Обработка → `mcp_ИнструментЗапросыИДанные`
3. Синоним: "Запросы и данные (инструмент)"
4. В модуле менеджера написать `ДобавитьИнструменты()` и `ВыполнитьИнструмент()`
5. Включить обработку в подсистему `mcp_КонтейнерыИнструментов`
6. Сохранить расширение → Обновить конфигурацию ИБ

### 5.2 Проверка работы

```powershell
# Проверить, что новый инструмент виден:
Invoke-RestMethod -Uri "http://localhost/PTM/hs/mcp/mcp" `
  -Method POST `
  -Body '{"jsonrpc":"2.0","method":"tools/list","id":1}' `
  -ContentType "application/json"

# Вызвать инструмент:
Invoke-RestMethod -Uri "http://localhost/PTM/hs/mcp/mcp" `
  -Method POST `

  -ContentType "application/json"
```
