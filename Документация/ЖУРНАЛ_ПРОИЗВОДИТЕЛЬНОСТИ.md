# Журнал производительности задач PTM

> Каждая задача фиксируется со замером времени этапов и описанием проблем/решений.
> Формат: YAML-блоки для удобного парсинга.

---

## Формат записи

```yaml
- task: "Краткое описание задачи"
  date: "YYYY-MM-DD"
  total_time: "ЧЧ:ММ:СС"
  phases:
    - name: "Фаза 0: Бэкап"
      time: "ММ:СС"
      status: "OK"
    - name: "Фаза 1: Анализ"
      time: "ММ:СС"
      status: "OK"
    - name: "Фаза 2: Реализация"
      time: "ММ:СС"
      status: "OK"
    - name: "Фаза 3: QC"
      time: "ММ:СС"
      status: "OK|RETRY"
    - name: "Фаза 4: Деплой"
      time: "ММ:СС"
      status: "OK|RETRY|ROLLBACK"
    - name: "Фаза 5: Мониторинг"
      time: "ММ:СС"
      status: "OK"
  problems:
    - description: "Описание проблемы"
      phase: "Название фазы"
      solution: "Как решили"
      time_lost: "ММ:СС"
  deploy_metrics:
    validate: "С.С сек"
    load: "С.С сек"
    check: "С.С сек"
    update: "С.С сек"
    monitor: "С.С сек"
  context_usage:
    total_tool_calls: 0          # Общее кол-во вызовов инструментов
    subagent_calls: 0            # Кол-во вызовов субагентов
    files_read: 0                # Кол-во вызовов read_file
    lines_read: 0                # Суммарно прочитано строк
    files_edited: 0              # Кол-во файлов отредактировано
    terminal_commands: 0         # Кол-во команд в терминале
    mcp_calls: 0                 # Кол-во вызовов MCP-инструментов
    searches: 0                  # Кол-во поисков (grep + semantic)
    by_phase:                    # Разбивка по фазам
      - phase: "Фаза 0"
        tool_calls: 0
      - phase: "Фаза 1"
        tool_calls: 0
```
